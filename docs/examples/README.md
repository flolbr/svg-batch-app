# Examples

## Membership demo

`membership-demo/` is a deliberately self-contained fixture set for development and browser testing.

It contains matching CSV and XLSX data, a safe SVG template, and expected mapping intent.

No file relies on external images, fonts, stylesheets, scripts, or network access.

The expected mappings describe fixture intent by source header. They are not a
serialized project file or an app-importable mapping format.
